# law-abstract-writing

法学论文**摘要与关键词写作** Skill，面向 MiMoCode / MiMo Desktop（及其他兼容 MiMoCode 技能格式的 agent）。

以三篇顶刊范文（《比较法研究》程啸、2019 年后《法学杂志》张建文与时诚、《清华法学》张弓长）为标本，
提炼出可复用的**四步公式**摘要写作法：**提出规范/司法难题 → 交代研究方法 → 阐释核心分析思路 → 给出结论与完善建议**，
并配套禁语清单、三种型态填空模板、关键词规则与自检清单。

> **本版为 2026-11-21 发布**：随 `law-lit-workflow` 的 P7 写作段集成（冲突裁决第 9 条，以本技能为摘要写作权威）。

## 解决的问题

1. **摘要写成引言**：出现研究意义、文献综述、章节介绍——四步公式之外的内容一律不进摘要。
2. **自我指称污染**：摘要中不出现「本文」「作者」「笔者」「文章」「本研究」等，观点宣告改为直陈判断句。
3. **分析思路空洞**：用「关系辨析 / 类型化 / 要件解释 / 适用边界」四类命题压出正文骨架，不写「第X章分析了……」。
4. **结论建议空喊口号**：落到「谁、依什么、怎么做」，用「应当/须/宜」规范助动词。
5. **关键词不合格**：3～5 个名词短语、中文分号分隔、每个都能在摘要中找到出处。

## 用法

用户说「帮我写摘要」「改摘要」「提炼关键词」「摘要和关键词」，或调用 `/law-abstract-writing` 时触发。
流程：第〇步从全文提取四要素（难题/方法/分析思路/结论建议）→ 判定型态（A 规范定性命题型 / B 问题驱动型 / C 立法技术辨析型）→
套模板 → 禁语扫描 → 自检清单 → 交付摘要＋关键词。

## 目录

- `SKILL.md`：四步公式、三种切入型态、句式库、三型态填空模板、禁语与替换法、关键词规则、自检清单、Troubleshooting
- `references/examples.md`：三篇顶刊范文的逐句四步映射与可复用句式库
- `locales/`：中英文显示名与简介

## 与 law-lit-workflow 的关系

`law-lit-workflow` 的 P7 写作段以本技能为**摘要写作权威**：摘要只写四步、零自我指称禁语铁律、
篇幅 300～400 字（学位论文 ≤500）、关键词 3～5 个且可溯源；其 `papercheck.py` 摘要上限已同步调整。
